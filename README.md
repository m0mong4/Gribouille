# Gribouille

A small Paint-style drawing project, made in class.

## Getting Started

 **Important: use the `gribouille_stable` branch**, it contains the working version.

-> https://github.com/m0mong4/Gribouille/tree/gribouille_stable

### 1. Get the project

```bash
git clone https://github.com/m0mong4/gribouille.git
cd Gribouille
git checkout gribouille_stable
```

### 2. Run the project

Open the project with **Eclipse** or **IntelliJ IDEA**, then run it from the IDE.

Happy doodling!
